# DeepAI Voice

Our own voice product: dictation (hold Fn and speak, text appears where you type), live translator for client calls in any language (subtitles, suggested replies, speak your reply into the call), and meeting notes for any call app.

Status: planning done, build starting (Phase 0). Mac first, then Windows and Linux.
