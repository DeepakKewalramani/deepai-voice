## 3. Tauri and hotkey
- FACT (crates.io): tauri 2.12.5, tauri-plugin-global-shortcut 2.4.1, global-hotkey 0.9.0, objc2 0.6.5, objc2-app-kit 0.3.2, core-graphics 0.25.0, tauri-nspanel 2.1.1.
- FACT (tauri-docs global-shortcut page): Rust handler matches `ShortcutState::Pressed` and `ShortcutState::Released`. Hold-to-talk via Released events is supported in Rust.
- FACT (global-hotkey `src/platform_impl/macos/mod.rs`): uses Carbon `RegisterEventHotKey` with pressed and released handlers.
- INFERENCE (downgraded): "global-shortcut cannot bind Fn alone". Basis: Carbon hotkeys need a non-modifier key and `Code::Fn` is documented as not generating a separate code. Confirm with a spike.
- INFERENCE: Fn/Globe requires a CGEventTap (flagsChanged) and Input Monitoring or Accessibility permission.
- INFERENCE: Carbon hotkeys need no TCC permission (well known, not re-verified).
- UNKNOWN: Rust 1.90+ minimum stated in 02 not re-found in the fetched doc page (grep did not match); cargo 1.99.1 satisfies it either way.
- INFERENCE: window options (`focusable`, `transparent`, `always_on_top`) and `macOSPrivateApi` no-op in 2.12.1+ were taken from docs.rs and config reference in 02; not re-fetched.

## 7. Claude Haiku cleanup
- FACT (claude-api skill, cached 2026-10-06): model id `claude-haiku-5-5`, $0.10 / $0.50 per MTok up to 100K prompt tokens, 1M context, no date suffix.
- FACT: Haiku 5.5 runs adaptive thinking by default, default effort `medium`; `thinking: {type: "disabled"}` accepted only at effort `high` or below.
- FACT: non-default `temperature`/`top_p`/`top_k` return 400 on Haiku 5.5; on API version `2026-10-21` sending them returns 400 on every model. Do not send them.
- FACT: assistant prefill returns 400 on Haiku 5.5.
- CORRECTED: forced `tool_choice` (`any` or named tool) is accepted on Haiku 5.5, but the response then has no thinking block. 06 had UNKNOWN.
- FACT: minimum cacheable prefix 512 tokens for Haiku 5.5 (skill says check live docs before relying on it).
- INFERENCE: for dictation, use `effort: "low"` with thinking omitted or `disabled`; measure latency.
- UNKNOWN: current Anthropic API data retention period (check commercial terms).

- INFERENCE (downgraded): orange mic indicator, Tauri capability model "deny unless granted". Well known, not re-fetched here.
- INFERENCE: wrap transcript in tags and mark it as data, plus output sanity check, reduces but does not remove prompt injection.
