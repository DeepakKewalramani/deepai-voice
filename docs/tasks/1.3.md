# 1.3: Silence, too-short and hallucination filters

- Phase: 1 | Branch: phase-0-foundation
- Depends on: 1.2 | Parallel: yes

## Goal
Implement robust filtering stages for audio buffers and transcribed text to discard clips under 300 ms, detect and drop silent audio buffers, eliminate known Whisper hallucinations (such as "[BLANK_AUDIO]" or trailing repetitive phrases), and filter conversational filler words.

## Owns (only these files may be changed)
- src-tauri/src/stt/filters/ (all files: mod.rs, silence.rs, hallucination.rs, fillers.rs)
- src-tauri/src/stt/mod.rs (additive module export)
- src-tauri/tests/filters_test.rs
- docs/tasks/1.3.md

## Done looks like (testable)
- [x] Duration filter: audio clips shorter than 300 ms (under 4,800 samples at 16 kHz) return None immediately without running transcription.
- [x] Silence gate: audio buffers with RMS amplitude below silence threshold (e.g. RMS < 0.005) return None.
- [x] Hallucination filter: detect and drop common Whisper hallucinations including "[BLANK_AUDIO]", lone "Thank you.", "Thanks for watching.", or repeated character/phrase loops.
- [x] Standalone filler filter: remove conversational fillers like "um", "uh", "ah", "hmm" when bounded by word boundaries or punctuation.
- [x] Preservation test: words containing filler substrings (e.g. "umbrella", "human", "Uhura") are preserved untouched.
- [x] Comprehensive unit tests in src-tauri/tests/filters_test.rs pass without network or external dependencies.
