# 1.1: Mic permission flow + 16 kHz mono capture in memory

## Goal
Capture microphone audio in memory as 16 kHz 16-bit mono PCM float buffers using cpal and rubato, with macOS microphone permission handling and level meter calculation, never writing audio to disk.

## Owns (only these files may be changed)
- src-tauri/src/audio/ (all files: mod.rs, capture.rs, resample.rs, meter.rs)
- src-tauri/tests/audio_test.rs
- src-tauri/Cargo.toml (additive dependencies only: cpal, rubato)
- docs/INSTALLED.md (dependency log)
- docs/tasks/1.1.md

## Done looks like (testable)
- [ ] Check and request macOS microphone permission via AVFoundation/CoreAudio (or cpal device query).
- [ ] Capture audio stream from default input device using cpal.
- [ ] Resample from native hardware device sample rate (e.g. 44.1 kHz, 48 kHz) to 16 kHz mono PCM (f32 samples) via rubato.
- [ ] Discard the first 50 ms of capture to avoid initial hardware click/transient artifacts.
- [ ] Enforce max recording length cap (maxRecordSeconds, default 120 s) to prevent unbounded memory growth.
- [ ] Real-time audio level calculation (RMS / peak dB) for UI level meter visualization without saving audio to disk.
- [ ] Zero audio samples or buffers written to disk: verify no temporary WAV or raw files created.
- [ ] Unit tests for resampler and RMS level meter pass in src-tauri/tests/audio_test.rs.

## Tests
- Automated: cargo test --test audio_test
- Manual:
  1. Launch app with RUST_LOG=info.
  2. Record 5 seconds of microphone speech.
  3. Verify level meter events are produced and values reflect voice intensity.
  4. Run find /tmp ~/Library/Caches -name "*audio*" to confirm zero audio files exist on disk.
