# 1.1: Mic permission flow + 16 kHz mono capture in memory

- Phase: 1 | Branch: phase-1/1.1-mic-capture

## Goal
Capture microphone audio in memory as 16 kHz 16-bit mono PCM float buffers using cpal and rubato, with macOS microphone permission handling and level meter calculation, never writing audio to disk.

## Owns (only these files may be changed)
- src-tauri/src/audio/ (all files: mod.rs, capture.rs, resample.rs, meter.rs)
- src-tauri/tests/audio_test.rs
- src-tauri/Cargo.toml (additive dependencies only: cpal, rubato, and macOS-only objc2, objc2-av-foundation, block2, approved by the human 31 Oct 2026)
- docs/INSTALLED.md (dependency log)
- docs/tasks/1.1.md

## Done looks like (testable)
- [x] Check and request macOS microphone permission via AVFoundation/CoreAudio (or cpal device query).
- [x] Capture audio stream from default input device using cpal.
- [x] Resample from native hardware device sample rate (e.g. 44.1 kHz, 48 kHz) to 16 kHz mono PCM (f32 samples) via rubato.
- [x] Discard the first 50 ms of capture to avoid initial hardware click/transient artifacts.
- [x] Enforce max recording length cap (maxRecordSeconds, default 120 s) to prevent unbounded memory growth.
- [x] Real-time audio level calculation (RMS / peak dB) for UI level meter visualization without saving audio to disk.
- [x] Zero audio samples or buffers written to disk: verify no temporary WAV or raw files created.
- [x] Unit tests for resampler and RMS level meter pass in src-tauri/tests/audio_test.rs.

## Tests
- Automated: cargo test --test audio_test

  2. Record 5 seconds of microphone speech.
  3. Verify level meter events are produced and values reflect voice intensity.
