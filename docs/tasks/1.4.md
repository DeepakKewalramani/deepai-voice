## Goal

## Review findings and fixes
Fixed 31 Oct 2026 after review (human approved decisions):
- SttProvider is async with `&self`, `Send + Sync`, via a boxed future (`SttFuture`). No new dependencies (no tokio, async-trait or futures in Cargo.toml).
- Local and RateLimit now fall through; BadRequest and Unsupported still halt. The old test asserting Local and RateLimit are not retryable encoded the old halting rule and was updated.
- Usage gained optional `tokens` and `characters`.
- Chain has a per-provider timeout (default 8s, `with_timeout`), implemented with a std timer thread because tokio is not a direct dependency. Timeout counts as ProviderError::Timeout and falls through.
- Known limit: local whisper is blocking and not run via spawn_blocking (no tokio), so the timeout cannot interrupt it mid-inference. Caller must poll off the UI thread.
- Local error messages carry only whisper-rs error text, model path or fixed strings, never transcript text (read-only check).
- New tests: local falls through, rate limit falls through, all-fail returns last error variant, timeout falls through, timeout alone, Send+Sync object safety, Usage metrics.
