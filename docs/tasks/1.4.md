# 1.4: SpeechToText trait + local adapter

- Phase: 1 | Branch: phase-1/1.4-stt-trait
- Depends on: 1.2, 1.3 | Parallel: no

## Goal
Define the core async SttProvider trait and ProviderError types in Rust matching ADR 0002, wrap local Whisper inference behind this trait, and implement the fallback chain that executes providers sequentially with timeout and error classification.

## Owns (only these files may be changed)
- src-tauri/src/stt/ (all files: mod.rs, trait_def.rs, chain.rs, local_adapter.rs)
- src-tauri/tests/stt_test.rs
- docs/tasks/1.4.md

## Done looks like (testable)
- [x] Define SttProvider trait with async method `transcribe(&self, audio: &Pcm16kMono, opts: &SttOpts) -> Result<Transcript, ProviderError>`.
- [x] Implement ProviderError classification matching ADR 0002: Auth, RateLimit, Timeout, Network, BadRequest, Server, Unsupported, Local.
- [x] Implement Usage structure returning audio_seconds, tokens/character metrics, and provider request identifiers.
- [x] Wrap local Whisper engine (from slice 1.2) as a concrete SttProvider implementation (LocalWhisperAdapter).
- [x] Fallback chain runner: executes configured providers in sequence; if first fails with retryable error (Timeout, Network, Server, Auth), second answers.
- [x] If user prompt causes BadRequest, the chain halts and surfaces the error instead of silently falling back.
- [x] Unit tests with mock providers verify fallback execution in src-tauri/tests/stt_test.rs.
