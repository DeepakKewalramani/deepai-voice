## Goal
Implement reliable automated paste injection at the active cursor using native synthetic key events (CGEvent Cmd+V on macOS, SendInput Ctrl+V on Windows) with atomic clipboard backup and restoration.

## Owns (only these files may be changed)
- src-tauri/src/paste/ (all files: mod.rs, macos.rs, windows.rs, clipboard.rs)
- src-tauri/tests/paste_test.rs
- src-tauri/Cargo.toml (additive dependencies only: arboard)
- docs/INSTALLED.md (dependency log)
- docs/tasks/2.4.md

## Done looks like (testable)
- [ ] Accessibility permission verification via AXIsProcessTrusted() before initiating paste.
- [ ] Save existing clipboard content and changeCount prior to overwriting clipboard with dictation text.
- [ ] Synthesize Cmd+V key down and key up events using CoreGraphics CGEvent on macOS.
- [ ] Configurable paste settle delay (default 100 to 150 ms) to accommodate slow Electron applications (Slack, VS Code).
- [ ] Restore previous clipboard content only if changeCount has not been modified by another application during the operation.
- [ ] Fallback handling: if paste fails or Accessibility is denied, save text in memory for "Copy last dictation" tray action.
- [ ] Automated tests using mock clipboard verify snapshot, restore, and changeCount guards in src-tauri/tests/paste_test.rs.

## Tests
- Automated: cargo test --test paste_test
- Manual:
  1. Copy arbitrary test string to system clipboard.
  2. Dictate a sentence into TextEdit, Notes, Slack, and Chrome.
  3. Verify dictated text appears at cursor.
  4. Press Cmd+V immediately afterwards and verify original clipboard content is restored.
