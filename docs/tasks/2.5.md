## Goal
Detect when the active focused element is a password or secure text field via macOS Accessibility API (kAXSubrole == kAXSecureTextFieldSubrole) and EnableSecureEventInput checks, preventing automatic paste and keeping dictated text out of the clipboard.

## Owns (only these files may be changed)
- src-tauri/src/paste/secure.rs
- src-tauri/tests/secure_field_test.rs
- docs/tasks/2.5.md

## Done looks like (testable)
- [ ] Query focused UI element via AXUIElementCopyAttributeValue for kAXFocusedUIElementAttribute and kAXSubroleAttribute.
- [ ] Detect secure entry fields: kAXSecureTextFieldSubrole or IsSecureEventInputEnabled().
- [ ] Invariant enforcement: when secure field is detected or state is unknown/ambiguous, automatic paste is aborted immediately.
- [ ] Clipboard protection: dictated text is NOT written to the system clipboard when focused on a secure field.
- [ ] dictated text is preserved in volatile memory for "Copy last dictation" tray menu option.
- [ ] User notification toast displayed: "Dictation paused: password field detected."
- [ ] Unit tests with mocked Accessibility responses verify safe refusal on secure inputs in src-tauri/tests/secure_field_test.rs.

## Tests
- Automated: cargo test --test secure_field_test
- Manual:
  1. Focus password input in Safari, Chrome, or 1Password.
  2. Speak a dictation phrase.
  3. Verify nothing is typed or pasted into the field, and clipboard contains zero secret dictation text.
