## Goal
Implement global hotkey capture supporting hold-to-talk with the physical Fn (Globe) key via macOS CGEventTap (Input Monitoring permission), with a cross-platform fallback to Ctrl+Option+Space via tauri-plugin-global-shortcut.

## Done looks like (testable)
- [ ] CGEventTap flagsChanged listener on macOS detecting physical Fn key press and release transitions.
- [ ] Fallback listener using tauri-plugin-global-shortcut registering Ctrl+Option+Space on macOS/Windows.
- [ ] Discard quick taps under 300 ms to avoid false trigger activations.
- [ ] Busy state guard: hotkey events received while transcription/pasting is already active are ignored.
- [ ] Permission check for Input Monitoring / Accessibility with deep link to System Settings when missing.
- [ ] 20/20 press and release pairs logged accurately in automated harness or interactive test script.

## Review findings and fixes
Reviewer findings, all verified in code and fixed:
1. Tap callback ignored kCGEventTapDisabledByTimeout/UserInput and had no port. Fixed: port stored in TapContext, pure `tap_action` decides ReEnable/HandleFlags/Ignore (unit tested), CGEventTapEnable(port, true) on disable, stuck Fn released.
2. CFMachPortCreateRunLoopSource null not checked. Fixed: returns an error, releases port and context.
3. Missing permission prompted and opened Settings every launch, no retry. Fixed: preflight, prompt once, return `FnTapStatus::PermissionMissing`; Settings opens only via `open_input_monitoring_settings()`; `retry_fn_tap(tx)` starts the tap later (guarded against double start).
4. Removed tautology tests `hotkey_event_*_equality`.
Not verified: real tap re-enable, retry after granting permission, prompt behavior (need a real Mac session).
