## Goal
Add toggle mode operation (press to start, press again to stop) alongside hold mode, and support distinct configurable shortcuts for Voice Dictation and Note Taker modes with live rebinding without app restart.

## Owns (only these files may be changed)
- src-tauri/src/hotkey/toggle.rs

## Done looks like (testable)
- [ ] Toggle mode state machine: first hotkey tap starts recording, second tap stops recording and triggers processing.
- [ ] Mode routing: separate hotkey definitions for Dictation Mode vs Note Taker Mode in settings.
- [ ] Live shortcut rebinding: modifying shortcuts in settings updates listeners immediately without restarting the app.
- [ ] Auto-stop safeguard: toggle mode automatically stops after maxRecordSeconds (default 120 s).
- [ ] State synchronization event emitted to frontend overlay window on start and stop.
- [ ] Unit tests for toggle state machine pass in src-tauri/tests/hotkey_toggle_test.rs.

## Tests
- Automated: cargo test --test hotkey_toggle_test
- Manual:
  1. Set mode to toggle. Tap hotkey once: overlay shows recording state.
  2. Tap hotkey again: recording stops and transcription proceeds.
  3. Rebind shortcut in settings to Ctrl+Shift+D and verify new key combination triggers immediately.
