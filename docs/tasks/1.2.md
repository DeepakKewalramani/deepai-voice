## Evidence (paste real output)
Machine: Intel i9-9980HK, macOS 15.7.4, CPU only, no Xcode (CLT + CMake). whisper-rs 0.16.0 (whisper-rs-sys 0.15.0) built from source with no errors.

Fixture: `say "hello world this is a test"` then `afconvert -f WAVE -d LEI16@16000 -c 1` to tests/fixtures/audio/sample_en.wav (1.54 s, 16 kHz mono Int16).

`cargo test --test local_whisper_test -- --nocapture` (debug test profile, 8 threads, greedy):
```
TIMING load_ms=1078 clip_ms=1541 first_ms=590 second_ms=566
test transcribes_fixture_with_base_en ... ok
test result: ok. 1 passed; 0 failed
```
- load_ms includes the 1 s silence warm-up. An earlier run: load 1039 ms, first 597 ms, second 587 ms.
- Transcript words match "hello world this is a test" exactly (0 percent WER on this clip).
- With models/ moved away the test prints `SKIP transcribes_fixture_with_base_en: model not found at ...` and passes.
- whisper.cpp stdout logging is routed away (`install_logging_hooks`), because it printed decoded tokens. Our own key=value events (stderr for now; slice 0.5 owns `tracing`, switch when it lands) carry only audio_ms, elapsed_ms, chars, threads, load_ms.

`npm run check`: see Handoff note.

Not verified: the 5 second clip budget from the manual steps (the fixture is 1.5 s; encoder cost is fixed per 30 s window, so a 5 s clip should be close); release-profile timings; Windows.
