## 2.3c: tiny idle capsule, hover controls, review fixes (2026-11-01)
What changed:
- Idle is a thin 36x8 capsule (8x36 upright), graphite at 55% with a 1px light rim, no content. Error 48x14, listening/thinking compact 72x20 (wave box 52x10, max amplitude 4, stroke 1.5).
- Hover: the drag worker polls the cursor every 50 ms (CGEventCreate + CGEventGetLocation, only once the mouse tap runs) and emits `overlay-hover {on}`. Opens at once inside the capsule plus 8 px, closes 400 ms after the cursor leaves the open capsule plus 8 px. The pill springs open (180 ms, transform and opacity, reduced-motion safe) into an 84x36 graphite glass capsule (36x84 upright) with two 28 px round buttons: Mic and Open (logo mark). Glyphs turn back upright on left/right. While listening the Mic button has the orange-to-violet ring and breathes. No text, no dot. Buttons have aria-labels ("Start dictation"/"Stop dictation", "Open DeepAI Voice"), tabindex -1.
- Clicks: through the existing active tap. While open, a press in the control capsule is swallowed; on a button it is a click that fires on release inside that button (never a drag); elsewhere it drags as before. A drag closes the controls first so the small capsule snaps. Clicks run in the worker thread.
- Mic: lib.rs wraps the `dictation::spawn` callback (`overlay_drag::dictation_callback`), the hotkeys call it through `call_dictation`, and `OverlayControl` (managed state) sends StartRecording/StopRecording on alternate clicks. A click is ignored while a key hold is recording; any status other than "REC" resets the toggle (follows `dictation-status` in Rust). Open reuses `show_main_window`.
- Window 112x56 (56x112 upright), turn window 112x112. `nearest_anchor` and persistence unchanged; old free placements are still normalised with the old 144x44 window.
- Review fixes: the snap jumps straight to the anchor when macOS Reduce motion is on (NSWorkspace `accessibilityDisplayShouldReduceMotion`, read once per drop); `save_placement` writes `overlay.json.tmp` then renames it.
- New pure tested functions: `hover_rect`, `button_rects`, `hover_zone`, `Rect::padded`, `HoverTracker`, `MicToggle`, `snap_plan`, `DragState` button presses (`PressTarget`, `DragAction::Click`).

Tests changed (by the new sizes, none deleted or weakened): overlay.rs window/anchor/origin/clamp/capsule numbers (144x44 to 112x56, 116x26 to 72x20), turn-window test now checks the hover and listening sizes; overlay_drag `Pressed` assertion gains `target: Body` and the test frame `buttons: None`; frontend size tests (idle 36x8, error 48x14 instead of equal to idle, listening 72x20, window 112x56, hover size included in the fit checks).
