## Goal
Implement a floating desktop pill overlay in Tauri and React that displays recording and processing states, audio level waveform, and quick cancel/done actions without ever stealing keyboard focus from active target applications.

## Owns (only these files may be changed)
- src/overlay/ (all files)

- docs/tasks/2.3.md

## Done looks like (testable)
- [ ] Transparent, non-activating Tauri overlay window configured with focusable: false, alwaysOnTop: true, and decorations: false.
- [ ] Active input caret in target application (TextEdit, VS Code, Notes) remains focused and blinking when overlay appears or animates.
- [ ] Visual state transitions: Idle (hidden), Recording (red dot / live audio level meter), Processing (spinner / wave animation), Done / Error toast.
- [ ] Smooth drag capability allowing the user to reposition the pill anywhere on screen.
- [ ] Display small provider indicator label (e.g. "Whisper local", "Sarvam") reflecting active STT engine.
- [ ] Interactive tests verifying focus retention during overlay show/hide cycles.

## 2.3b: four anchors, upright on left/right, new size (2026-11-01)
What changed:
- Exactly four anchors: top centre (below the notch, default), bottom, left, right centre. A drop snaps to the anchor whose centre is nearest the capsule centre, on the monitor under the capsule (primary as fallback). No free offset (always 0.5).
- Left and right: window swapped to 44x144 and the capsule turned 90 degrees in CSS (`rotate`), wave included. Top and bottom stay horizontal in a 144x44 window.
- Size: idle/error 76x24, listening/thinking 116x26, wave box 88x14, max amplitude 5, stroke 1.75, error line 38.
- Snap: 8 eased steps over 150 ms in the drag worker (never in the tap callback), in a 144x144 turn window so the turn never clips, then the anchor size. Emits `overlay-position` then `overlay-drag {dragging:false}`.
- overlay.json: old files with any edge/offset load and are moved to the nearest anchor and re-saved; invalid file means top.
- Pure tested functions: `window_size_for`, `anchor_window_rect`, `nearest_anchor`, `normalise_placement`, `capsule_rect_in` (upright hit rect, swapped and centred), `turn_origin`, `snap_steps`.

Tests changed (legitimately, by the new behaviour): size numbers in overlay.rs placement/clamp/hit tests (144x44 window), capsule_rect left/right (upright, centred), the five snap tests (anchor, offset 0.5; `snap_placement` signature now `(screen, center)`), frontend size and wave amplitude tests.
